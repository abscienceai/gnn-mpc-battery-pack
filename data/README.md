# Data

The final manuscript uses MATR and HUST only.

## Final data roles

### MATR

MATR is used to inform the LFP ECM/SOH parameterization underlying the simulated training and evaluation plant.

The publication repository includes the frozen resulting ECM table:

```text
results/ecm/ecm_params_20260630_202031.parquet
```

The final processed MATR collection contained 180 batteries.

The study should be described as **MATR-informed** or **dataset-informed**, not as a fully data-derived electrochemical model. In particular, R0 and SOH are informed by the processed table, while other model terms include chemistry-level defaults.

### HUST

HUST is used as a held-out source of measured charging current, time, and voltage trajectories.

The final processed collection contained 77 LFP cells.

For HUST replay, place BatteryML-format processed files under:

```text
data/processed/BatteryML/HUST/
```

For example:

```text
data/
└── processed/
    └── BatteryML/
        └── HUST/
            ├── HUST_1-1.pkl
            └── ...
```

The replay script uses real `time_in_s` and physical interpolation at 60 s intervals. It does not use index-stride sampling.

HUST replay is an external measured-protocol replay. Simulated responses are still generated by the study's MATR-informed ECM/thermal plant, so it is not external plant validation.

## BatteryML

The preprocessing workflow uses the BatteryML project:

https://github.com/microsoft/BatteryML

Follow the upstream BatteryML instructions to obtain and preprocess MATR and HUST data, then place the resulting processed files in the directory structure above.

Raw and processed third-party datasets are intentionally excluded from this Git repository.

## Datasets excluded from the final manuscript evaluation

CALCE, RWTH, NASA, Oxford, NMC, and LCO development experiments are not part of the final publication evaluation and are not required for reproducing the manuscript's final results.
