# Data

The manuscript uses MATR and HUST LFP data in different roles.

## MATR

MATR informs the LFP ECM/SOH parameterisation used by the simulated training and evaluation plant. The repository includes the frozen resulting ECM table:

```text
results/ecm/ecm_params_20260630_202031.parquet
```

The processed MATR collection used for this study contained 180 batteries. The plant should be described as MATR-informed or dataset-informed rather than fully data-derived: processed data inform R0 and SOH, while other model terms retain chemistry/model defaults.

## HUST

HUST is held out from the MATR-based pipeline and supplies measured charging current, physical time, and voltage context for protocol replay. The processed collection used for the study contained 77 LFP cells.

For reproduction, place BatteryML-format processed HUST files under:

```text
data/processed/BatteryML/HUST/
```

The replay uses physical timestamps and interpolation at 60 s intervals. Simulated state responses are still generated by the MATR-informed study plant, so the experiment is measured-protocol replay rather than external plant validation.

## Obtaining the datasets

The preprocessing workflow uses BatteryML:

https://github.com/microsoft/BatteryML

Obtain MATR and HUST from their original providers and follow the applicable licenses/terms, then preprocess them with BatteryML and place the required files in the path above.

Raw and processed third-party datasets are intentionally not redistributed in this repository.
